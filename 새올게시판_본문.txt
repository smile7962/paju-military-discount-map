파주시 관내 군 장병 및 사회복무요원이 이용할 수 있는 할인업소를
지도에서 손쉽게 찾아볼 수 있도록 「파주 군장병 할인업소 지도」 서비스를
안내드립니다. 별도 앱 설치나 로그인 없이 스마트폰·PC 웹브라우저에서
바로 이용하실 수 있습니다.


○ 서비스 개요
  - 대상 : 군 장병, 사회복무요원
  - 등록 업소 : 총 189개소 (파주시 12개 권역)
  - 업종 : 음식점 · 카페/간식 · 미용 · 목욕 · 숙박
  - 사회복무요원 적용 업소 : 74개소
  - 이용 요금 : 무료 (로그인·설치 불필요)


○ 이용 방법 (4단계)
  1. 권역 선택 : 금촌·운정·문산·법원·탄현·적성 등 12개 권역 중 선택
  2. 업종 선택 : 원하는 업종을 선택해 결과 좁히기 (권역+업종 동시 적용)
  3. 확인 : 지도 마커 또는 목록에서 업소 위치·할인 내역 확인
  4. 이용 : 상세 화면에서 [전화] 또는 [카카오맵 길찾기]로 바로 연결


○ 접속 방법
  - 주소(URL) : https://smile7962.github.io/paju-military-discount-map/
  - QR코드 : 붙임 이미지의 QR코드를 스마트폰 카메라로 스캔
  ※ 카메라로 QR코드를 비추면 별도 설치 없이 브라우저에서 바로 열립니다.


○ 홈 화면에 추가하여 앱처럼 사용하기
  - iPhone(Safari) : 접속 → 하단 [공유] 버튼 → [홈 화면에 추가]
  - Android(Chrome) : 접속 → 우측 상단 [메뉴(⋮)] → [홈 화면에 추가]
  ※ 설치하면 홈 화면 아이콘을 눌러 앱처럼 바로 실행할 수 있습니다.
